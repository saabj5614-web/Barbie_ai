# Barbie AI

Barbie AI is a premium Android assistant foundation focused on voice-first interaction, Roman Urdu/Urdu-first responses, privacy-aware permissions, AI provider fallback, and future phone/file/GitHub tools.

## Current build
- Android app foundation
- Premium Barbie UI
- Microphone permission flow
- Provider-secret placeholders
- Backend architecture notes
- Hindi output intentionally disabled by design

## Security
Never place AI, GitHub, Telegram, database, or other private tokens inside the APK or source tree. Use backend environment secrets.

## Important
This repository is the new Barbie AI project. The older `Barbie_mini_bot` repository is not used or modified by this project.
